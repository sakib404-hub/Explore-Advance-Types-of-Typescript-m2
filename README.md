# 📘 TypeScript Concepts & Practice Repository

This repository contains a collection of TypeScript examples and practice files covering core to advanced concepts. It is designed to help understand TypeScript features through simple, well-structured code snippets.

---

## 🚀 Overview

In this repository, various important TypeScript topics are explored, including:

- Enums and their alternatives  
- Generics and constraints  
- Interfaces and type assertions  
- Mapped types and conditional types  
- Utility types and advanced type manipulation  

Each concept is implemented in separate files for clarity and easy learning.

---

## 📂 File Structure

| File Name | Description |
|----------|------------|
| `enum.ts` | Basic usage of TypeScript enums |
| `AlternativeEnum.ts` | Alternative approaches to enums |
| `generic.ts` | Introduction to generics |
| `genericWithFunction.ts` | Generics used with functions |
| `genericWithInterface.ts` | Generics used with interfaces |
| `constrains.ts` | Generic constraints and usage |
| `keyOf.ts` | Using `keyof` with generics |
| `interface.ts` | Interfaces and type assertion basics |
| `typeAssertion.ts` | Detailed examples of type assertions |
| `conditional.ts` | Conditional types in TypeScript |
| `mappedTypes.ts` | Mapped types explained |
| `utilityTypes.ts` | Built-in utility types in TypeScript |

---

## 🧠 Topics Covered

| Category | Topics |
|----------|--------|
| 🔹 Enums | Standard enums <br> Alternative patterns (objects, union types) |
| 🔹 Generics | Generic types <br> Generic functions <br> Generic interfaces <br> Constraints using `extends` <br> `keyof` with generics |
| 🔹 Interfaces & Type Assertion | Defining interfaces <br> Type casting using assertions |
| 🔹 Advanced Types | Conditional types <br> Mapped types <br> Utility types (`Partial`, `Pick`, `Readonly`, etc.) |

## 🎯 Goal

The goal of this repository is to:
- Strengthen TypeScript fundamentals  
- Understand advanced type features  
- Practice real-world TypeScript patterns

```bash
git clone 'repository link'
```

```bash

```

```bash
tsc filename.ts

```
